# PresentMon CN 1.1.2

基于 PresentMon 上游提交 `e7825637` 制作的安装版捕获修复版本。

## 本次修复

- 修复安装版未在运行目录放置自动目标排除名单，导致软件误选系统或受保护进程的问题。
- 修复自动选择目标后覆盖层反复崩溃、连续弹出大量错误并造成捕获无法正常启动的问题。
- 若某个自动目标仍无法初始化覆盖层，程序会暂停自动选择并释放进程选择框，避免不断重试同一进程。
- 启动器现在会检查安装版必需的目标排除名单，避免不完整安装继续运行。
- 新电脑若尚未加入“性能日志用户”本地组，启动器会自动请求管理员授权，避免因 ETW 权限不足而无法捕获。
- 保留 1.1.1 的高 DPI 清晰显示和窗口尺寸修复。

## 下载选择

- `PresentMon-CN-1.1.2-Setup-x64.exe`：推荐日常使用，可直接覆盖安装 1.1.0 或 1.1.1。
- `PresentMon-CN-1.1.2-Portable-x64.zip`：完整解压后，双击根目录的 `PresentMon-CN.exe`。
- `SHA256SUMS.txt`：用于核对下载文件的 SHA-256。

## 使用说明

HWiNFO 联合捕获方式没有变化：先打开 HWiNFO Sensors 并启用 Shared Memory Support，之后只需使用 PresentMon CN 中设置的捕获快捷键。安装升级不会删除“文档\PresentMon-CN”中的个人配置和捕获数据。

首次在未配置捕获权限的电脑上启动时，Windows 可能显示用户账户控制提示；确认后即可正常使用。已属于“性能日志用户”本地组的账户不会出现该提示。

本项目为个人构建，目前没有商业代码签名。Windows 可能显示“未知发布者”或 SmartScreen 提示，请确认下载来源并核对校验文件。
