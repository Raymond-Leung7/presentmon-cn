# PresentMon CN 1.1.3

基于 PresentMon 上游提交 `e7825637` 制作的黑屏与退出故障修复版本。

## 本次修复

- 撤回 1.1.2 中自动以管理员身份启动整套程序的方案，修复部分新电脑打开后只有黑色窗口的问题。
- 首次使用且缺少捕获权限时，管理员授权现在只用于把当前 Windows 账户加入“性能日志用户”本地组；主程序不会以管理员身份运行。
- 权限修复启动器只从 Windows 系统目录加载系统组件，避免管理员授权阶段加载安装目录中的同名文件。
- 检查浏览器界面的初始化和创建结果，失败时立即退出，不再留下无法使用的黑色外壳窗口。
- 修复点击关闭后窗口消失、进程却继续留在后台的问题；异常关闭超过 5 秒时会自动清理。
- 修复上述残留进程导致再次启动时无法恢复窗口、也无法结束旧实例的问题。
- 保留 1.1.2 的安装版捕获、自动目标选择、高 DPI 显示和 HWiNFO 联合捕获修复。

## 从 1.1.2 恢复

如果 1.1.2 当前仍黑屏或留在后台，最简单可靠的处理方式是：

1. 重启一次 Windows，清除旧版残留进程。
2. 安装 `PresentMon-CN-1.1.3-Setup-x64.exe`，可以直接覆盖旧版。
3. 普通双击启动，不要选择“以管理员身份运行”。
4. 如果软件提示修复捕获权限，选择“是”并完成管理员授权，然后注销 Windows 并重新登录一次。

## 下载选择

- `PresentMon-CN-1.1.3-Setup-x64.exe`：推荐日常使用，可直接覆盖安装 1.1.0 至 1.1.2。
- `PresentMon-CN-1.1.3-Portable-x64.zip`：完整解压后，双击根目录的 `PresentMon-CN.exe`。
- `SHA256SUMS.txt`：用于核对下载文件的 SHA-256。

## 使用说明

HWiNFO 联合捕获方式没有变化：先打开 HWiNFO Sensors 并启用 Shared Memory Support，之后只需使用 PresentMon CN 中设置的捕获快捷键。安装升级不会删除“文档\PresentMon-CN”中的个人配置和捕获数据。

卸载 PresentMon CN 不会自动把账户移出“性能日志用户”组，避免撤销由其他软件或管理员配置的同一项 Windows 权限。

本项目为个人构建，目前没有商业代码签名。Windows 可能显示“未知发布者”或 SmartScreen 提示，请确认下载来源并核对校验文件。
